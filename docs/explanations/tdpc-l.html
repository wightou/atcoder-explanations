TDPC L - 猫

問題ページ解答例

考え方

ABCでいうと、難しめD問題級。

わりと普通の動的計画法を、少し高速化するだけ。

DPテーブルとして、末尾の猫から左 $1$ 以内にいる猫の最小番号ごとの最大スコアの半分をもつ。
半分にするのは、距離 $1$ 以内にいるペアに両方同じ幸福値が加算されるところ、片方だけ処理するため。

そうしておいて、末尾に猫を $1$ 匹ずつ追加する。

猫 $i$ を追加したとき、そこから左 $1$ 以内にいる猫の最小番号が $j$ であるデータは、以下の和である。

  • 猫が $i-1$ までだったときの、猫の最小番号が $j$ 以下での最大値
  • 猫 $i$ と、猫 $j$ から $i-1$ までとの幸福度の合計

これらは両方とも累積的に処理できるため、猫 $1$ 匹の追加は $O(N)$ でできる。
よって、全体での計算量は $O(N^2)$ となる。

入力例1での動作

入力を受け取る。

n: 3
f:
{0, 2, 3}
{2, 0, -10}
{3, -10, 0}

コードでは猫を $0$ から始まる番号で扱う。
dp[j] は、末尾の猫から左 $1$ 以内にいる猫の最小番号が $j$ の場合の最大スコアの半分とする。

最初は全て $0$ である。

dp: {0, 0, 0}

猫 $0$ を追加しても、まだペアは存在しない。

dp: {0, 0, 0}

猫 $1$ を追加する。
猫 $0$ と猫 $1$ の幸福度は $2$ なので、更新後は次のようになる。

dp: {2, 0, 0}

次に猫 $2$ を追加する。
最初の sum は、猫 $2$ とそれ以前の猫との幸福度の合計である。

sum = 3 + (-10) = -7

$j=0$ では、それまでの最大値 $2$ に sum を足す。

dp[0] = 2 + (-7) = -5

その後、猫 $0$ との幸福度 $3$ を sum から外す。

sum = -10

$j=1$ では、それまでの最大値は引き続き $2$ なので、

dp[1] = 2 + (-10) = -8

となる。
さらに猫 $1$ との幸福度 $-10$ を sum から外すと、sum = 0 となる。

$j=2$ では、

dp[2] = 2 + 0 = 2

となる。
よって、最終的な DP テーブルは次のようになる。

dp: {-5, -8, 2}

最大値は $2$。
DP テーブルではスコアの半分を持っているので、$2$ 倍した $4$ が答え。
