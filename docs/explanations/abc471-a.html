ABC471 A - Nine or Nein

9か否か

問題ページ解答例
目次
  • 考え方
  • 入力例1での動作
  • 注意点
  • 別解

考え方

入力は整数が $2$ つなので、int 型の変数を $2$ つ用意し、cin で入力を受け取る。

$4$ つの条件のうち $1$ つでも成り立てば、という条件は、以下のように書ける。

if (条件1||条件2||条件3||条件4) {
  処理
}

足し算、引き算、掛け算、までは普通に a+b==9 a-b==9 a*b==9 でよい。
問題は割り算で、a/b==9 と書くと、 $a$ が $19$ で $b$ が $2$ のような場合に誤判定する。
かといって小数で判定するのは不安があるので、a==9*b で判定すること。

あとは、条件に当てはまるかどうかで出力を Nine か Nein かを変更すればよい。

if 文の中で直接 cout してもいいし、事前に出力用文字列を用意してもよい。

余談だが、Nein はドイツ語で「いいえ」を意味する単語で、発音は「ナイン」である。

入力例1での動作

$a=16$, $b=7$ を受け取る。
出力用文字列は、最初 Nein である。

$4$ つの条件をそれぞれ確認する。

  • a+b==9 は、$16+7=23$ なので成り立たない。
  • a-b==9 は、$16-7=9$ なので成り立つ。
  • a*b==9 は、$16\times7=112$ なので成り立たない。
  • a==9*b は、$16\neq9\times7=63$ なので成り立たない。

$4$ つの条件のうち a-b==9 が成り立つので、if 文の条件全体が真になる。
よって、出力用文字列を Nine に変更する。

最後に出力用文字列を出力するので、答えは Nine となる。

注意点

特になし。

別解
