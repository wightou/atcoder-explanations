無効票

考え方

実行速度に気を使わなくていいという意味ではB問題で間違いないのだが、かなり複雑。

まず、各票が誰の票になるのかの調査の設計が難しい。
これは、全員の名前と比較して、$2$ つのデータに記録するとよい。
$1$ つめのデータは、名前が正確に一致する人がいるかどうかの bool 型。
$2$ つめのデータは、名前が $1$ 文字違いの人の一覧である vector<string> 型。

このデータを作るには、票ごとに全員の名前と照らし合わせればよい。
まず、文字数が違えば、比較する意味もないので何もせず次の名前へ。
文字数が同じなら、同じ位置にあるのに文字が違う組が何ヶ所あるか数える。
$0$ ヶ所なら bool の方を true にし、$1$ ヶ所なら正しい名前を vector<string> の末尾に加える。
全員見終わった段階で、これが有効票であるパターンは以下の $2$ つである。

  • bool が true であるなら、票に書いてある名前の人に $1$ 票
  • bool が false で、vector<string> の要素数が $1$ なら、そこにある名前の人に $1$ 票

ただし、これらは投票先の名前がわかるが、何番の候補者なのかを見るのは難しい（できなくはない）。
そこで、最初に全員分の名前をキーにした map を作ってしまうとよい。
各票ごと誰に票を入れるかわかったところで名前のまま票をカウントしていけばよい。
出力前に map を見て名簿順に票数を確認するのは、ここまでの作業と比べれば非常に簡単なことである。

入力例1での動作

入力を受け取る。

n: 5
m: 8
s: {"takahashi", "aoki", "sato", "kato", "kano"}
t: {"aoki", "takanashi", "sano", "atcoder",
    "chokudai", "kato", "aoki", "yato"}

まず、候補者全員の得票数を $0$ として map に記録する。

各投票用紙について、名前が完全一致する人がいるかどうかと、$1$ 文字違いの候補者の一覧を調べる。

投票用紙 書かれた名前 完全一致 $1$ 文字違いの候補者 投票先
$1$ aoki あり なし aoki
$2$ takanashi なし takahashi takahashi
$3$ sano なし sato, kano 無効票
$4$ atcoder なし なし 無効票
$5$ chokudai なし なし 無効票
$6$ kato あり sato kato
$7$ aoki あり なし aoki
$8$ yato なし sato, kato 無効票

$6$ 枚目は sato と $1$ 文字違いだが、kato に完全一致するため、kato に投票される。

全ての投票を処理すると、候補者ごとの得票数は次のようになる。

takahashi: 1
aoki: 2
sato: 0
kato: 1
kano: 0

これらを名簿順に出力するので、答えは上から $1,2,0,1,0$ となる。
