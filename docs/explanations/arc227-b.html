考え方

仮に $B$ が構成できたとして、値 $i$ がどこに入れられるか考えてみる。
以下、順番は 0-indexed で表記する。

まず、条件を満たしている以上、$i$ 番目より前は全て $i$ 未満の数。
よって、$i$ 番目以後、次に $i$ 未満の値が初めて登場する前まで。
これが、値 $i$ を使用できる範囲である。

ということは、$i$ 番目は「それまでに未使用な $i$ 以下の数で最大のもの」でよい。

カウンティングソートと stack を利用すれば、計算量は $O(N)$ となる。

入力例1での動作

入力を受け取る。

n: 4
a: {3, 0, 1, 0}

各値の個数を数えると、counters は次のようになる。

counters: {2, 1, 0, 1}

que を、現在使用できる未使用の値を小さい順に持つ stack として使う。

$i=0$ では、値 $0$ を $2$ 個 que に追加する。
この中で最大の値 $0$ を採用する。

que: {0}
result: {0}

$i=1$ では、値 $1$ を $1$ 個 que に追加する。
最大の値 $1$ を採用する。

que: {0}
result: {0, 1}

$i=2$ では、値 $2$ は存在しないので何も追加しない。
que に残っている最大の値 $0$ を採用する。

que: {}
result: {0, 1, 0}

$i=3$ では、値 $3$ を $1$ 個 que に追加する。
最大の値 $3$ を採用する。

que: {}
result: {0, 1, 0, 3}

最後まで構築できたので、Yes と 0 1 0 3 を出力する。
