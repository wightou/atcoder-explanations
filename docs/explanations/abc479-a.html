ABC479 A - Odd Index Sum

奇数番目の和

考え方

実は、ABC403Aと全く同じ問題。

入力は整数と数列が $1$ つずつ。
int 型の変数と vector を $1$ つずつ用意し、cin で入力を受け取る。

これの奇数番目を合計したいのだが、まず $1$ つ注意すべきことがある。
問題は 1-indexed つまり先頭を $1$ 番目として番号をつけてある。
ところが、C++ではコンピューターは 0-indexed つまり先頭を $0$ 番目として番号をつけてある。
よって、問題で言う奇数番目は、C++的には偶数番目になる。

さて、$A$ の中身を全て合計するコードの一例は以下。

int sum = 0;
for (int i=0; i<n; i++) {
  sum += a.at(i);
}

これを偶数番目だけ足すようにするにはどうするか。
方法は大きく $2$ つある。

$1$ つは、i++ のところを i+=2 に変えてしまうこと。
$i$ の値が毎周 $2$ 増えるため、$0$ 番目、$2$ 番目、$4$ 番目、と合計してくれる。

もう $1$ つは、sum の加算を if (i%2==0) の中に入れてしまうこと。
奇数番目のときには足し算が実行されなくなるので、偶数番目だけ足されることになる。

どちらの方法でもいいのでこれを実行し、求まった合計値を cout で出力すればよい。
解答例では前者の方法を用いている。

入力例1での動作

入力を受け取る。

n: 5
a: {3, 1, 4, 1, 5}

数列の要素と添字の対応は、a[0]=3、a[1]=1、a[2]=4、a[3]=1、a[4]=5 となる。
このうち、問題文でいう奇数番目の要素は、a[0]、a[2]、a[4] である。

奇数番目にあたる要素を、先頭から順に足していく。

  • $1$ 番目の $3$ を選び、合計は $3$ となる。
  • $3$ 番目の $4$ を加え、合計は $3+4=7$ となる。
  • $5$ 番目の $5$ を加え、合計は $7+5=12$ となる。

したがって、答えは $12$ となる。
