考え方

各人それぞれ、移動を $4$ つに分類して考える。

  • すれ違いながら右に移動する
  • すれ違いながら左に移動する
  • すれ違わずに右に移動する
  • すれ違わずに左に移動する

まず、すれ違わない分を求める。
これは、左右移動を両方やる意味はない。
すれ違い分だけ考慮したうえで、最小移動回数を選べばよい。

すれ違いによる移動量は、以下の $2$ つの差の分になる。

  • 自分より左から出発して、自分より右へ行く、という人の数だけ左へ強制移動
  • 自分より右から出発して、自分より左へ行く、という人の数だけ右へ強制移動

これらをそれぞれ数えるのはかなり大変だが、差分だけでいいなら簡単になる。
両方に「自分より左から出発して、自分より左へ行く」という人の数を足してしまえばよい。
それぞれの値は変わるが、差分は変わらないまま以下のようになる。

  • 自分より左から出発する、という人の数だけ左へ強制移動
  • 自分より左へ行く、という人の数だけ右へ強制移動

これは、$S$ と $T$ をそれぞれソートしたときに自分が何番目になるのかを調べればよい。

以上で、初期位置に強制移動分を加算した位置から、行先までの距離がすれ違わない移動の回数が求まる。
よって、まずはこれを全員分加算する。

ここに、すれ違い回数を加算する。
これは $S$ の昇順に並べたときの $T$ の転倒数である。
座標を使うと最大 $10^9$ まであるのでFenwick木に載せられない。
これの回避方法は $2$ つある。

$1$ つは座標圧縮する方法。
といっても追加で何か書く必要はない。
「$S$ と $T$ をそれぞれソートしたときに自分が何番目になるのか」のデータ自体が、座標圧縮結果である。

もう $1$ つは、Fenwick木を使う方法ではなく、マージソートで求める方法を使うこと。
こちらならやることはただのソートなので値の大きさに影響されない。

いずれにしても、計算量は $O(N \log N)$ で解ける。

入力例1での動作

入力を受け取る。

n: 3
s: {4, 2, 5}
t: {3, 4, 1}

初期位置の小さい順に並べると、人 $2,1,3$ の順になる。
目標位置の小さい順に並べると、人 $3,1,2$ の順になる。

各人について、初期位置と目標位置での順位を $0$ から数える。
この順位の差から、すれ違いによる左右への強制移動の差を求める。

人 初期位置 $S_i$ 目標位置 $T_i$ 初期順位 目標順位 順位の差 すれ違わない移動回数
$1$ $4$ $3$ $1$ $1$ $0$ $\lvert 4+0-3\rvert=1$
$2$ $2$ $4$ $0$ $2$ $2$ $\lvert 2+2-4\rvert=0$
$3$ $5$ $1$ $2$ $0$ $-2$ $\lvert 5-2-1\rvert=2$

よって、すれ違わない移動回数の合計は $1+0+2=3$ となる。

次に、初期位置の小さい順に並べたときの目標順位は $\{2,1,0\}$ となる。
これの転倒数を求める。
Fenwick木で目標順位ごとの出現人数を管理し、すでに登場した自分より大きい順位の人数を数える。

人 目標順位 登場済の大きい順位 加える転倒数 転倒数の合計 管理する人数（順位 $0,1,2$）
$2$ $2$ なし $0$ $0$ $\{0,0,1\}$
$1$ $1$ $2$ $1$ $1$ $\{0,1,1\}$
$3$ $0$ $1,2$ $2$ $3$ $\{1,1,1\}$

管理する人数はFenwick木で扱う元の配列として示している。
すれ違い回数は転倒数の $3$ 回なので、答えは $3+3=6$ となる。

注意点

移動回数の合計は、int 型からはみ出る。
long long 型を用いること。

別解

人がいないところにも全てダミーの人を入れる。
ただし、ダミーの人同士が初期位置と目的位置で同じ並び順になるようにする。

こうすると、全ての移動がすれ違いになる。
そのため、初期位置順に並べたときの行先位置の転倒数を求めればよい。
やることの解説は以上である。

ただし、実装はかなりハード。
まず、そもそも最大 $10^9$ 人が並ぶので、単純に配列で持つことすらできない。
そのため、ダミーの人が連続しているところは圧縮して扱う必要がある。

そして、転倒数を求めるにも、位置が $10^9$ まであるのでFenwick木が単純に持てない。
よって、座標圧縮とセットにした特殊なFenwick木を用意することになる。
（座標圧縮内蔵のを自力で書くか、自力座標圧縮とAtCoder LibraryのFenwick木をアドリブで組み合わせる）

これらを全て気合で実装して、計算量 $O(N\log N)$ で解ける。
