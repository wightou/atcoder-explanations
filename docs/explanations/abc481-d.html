ABC481 D - Autopilot

自動操縦

問題ページ解答例
目次
  • 考え方
  • 入力例1での動作
  • 注意点
  • 別解

考え方

移動コストが $0$ か $1$ なので、$01$ 最良優先探索でよい。
全辺コスト $1$ でグラフを作った後で、各頂点該当する辺を調べてコストを $0$ に書き換えればよい。
通常の隣接リストで持っていれば、中身をそれぞれソートするだけで簡単にできる。

典型問題の中身を正しく知っていれば非常に簡単、中身を知らずに使っていれば難問。
計算量は最小番号の調査の方法次第で、$O(N+M)$ または $O(N+M\log M)$ である。

入力例1での動作

入力を受け取る。
惑星番号は 0-indexed に変換するため、入力後の変数は以下のようになる。

n: 7
m: 10
s: 1
t: 0
u: {1, 1, 3, 3, 2, 2, 2, 4, 5, 5}
v: {4, 3, 1, 2, 0, 4, 5, 5, 0, 6}

以下では、惑星番号は問題文と同じ 1-indexed で説明する。

各惑星から出発する航路の行き先を調べ、番号が最小の行き先への移動コストを $0$、それ以外を $1$ とする。

出発する惑星 コスト $0$ の行き先 コスト $1$ の行き先
$1$ なし なし
$2$ $4$ $5$
$3$ $1$ $5,6$
$4$ $2$ $3$
$5$ $6$ なし
$6$ $1$ $7$
$7$ なし なし

惑星 $2$ を開始地点として、01最良優先探索を行う。

まず、コスト $0$ の移動だけで惑星 $2\to 4\to 2$ と進めるため、消費燃料 $0$ で到達できる惑星は $2,4$ である。

コスト $0$ の辺で進める頂点は、次の探索対象の先頭へ追加する。
コスト $1$ の辺で進める頂点は、末尾へ追加する。
これにより、消費燃料の少ない順に調べられる。
ここからコスト $1$ の辺を使うと、惑星 $2\to 5$ または惑星 $4\to 3$ へ進める。

惑星 $5$ からはコスト $0$ の辺を使って惑星 $6$、さらに惑星 $1$ へと進める。
つまり、惑星 $2\to 5\to 6\to 1$ と進めば、消費燃料は $1$ である。

消費燃料 $0$ では惑星 $1$ に到達できないため、答えは $1$ となる。

注意点

特になし。

別解

一応、Dijkstra法でも解ける。
計算量は $O(N+M)\log M$ となるが、今回の制約なら間に合う。
とはいえ、$01$ 最良優先探索の絶好の練習問題を、大きな武器で殴ってチャンスを潰すのはもったいない。
