## 考え方

まず、このような問題において、大きい側に何かするのは基本的に大変。
そこで、その頂点が「足してもらうことができなかった数」の方の合計を出す。
つまり、小さい方に番号を足していき、最後に合計を $N(N-1)/2$ から引くことにする。

すると、木の重心を根とした根付き木で簡単に解くことができる。
木の重心の定義から、どの辺も、葉側の方が小さい成分になる。
よって、最初に各辺、葉側にある頂点の $x$ に辺番号を足す。
そして根から葉に向かって木上の累積和をとれば、「足してもらうことができなかった数」の合計である。
前述のとおり、それぞれを $N(N-1)/2$ から引けばよい。

木の重心を求める方法はいろいろある。
今回は、根付き木化のための幅優先探索または深さ優先探索のコードがあるので、それを流用するとよい。
適当に根を決めて根付き木化したとき、以下を満たす頂点が $1$ つだけある。
それが重心の $1$ つであり、奇数頂点なので唯一の重心である。

- 自分の子がすべて「自身以下の部分木サイズが $N/2$ 以下」
- 自分自身は「自身以下の部分木サイズが $N/2$ より大きい」

計算量は重心の求め方にもよるが、上で述べた方法でなら $O(N)$ である。

## 入力例1での動作

入力を受け取る。
頂点番号は `0-indexed` に変換する。

```text
n: 5
u: {1, 0, 0, 0}
v: {3, 4, 3, 2}
```

まず頂点 $0$ を仮の根として、各頂点の部分木サイズを葉側から求める。

<!-- table-row-header: true -->
| 頂点 | 子 | 部分木サイズ |
| ---: | :--- | ---: |
| $0$ | $4,3,2$ | $5$ |
| $1$ | なし | $1$ |
| $2$ | なし | $1$ |
| $3$ | $1$ | $2$ |
| $4$ | なし | $1$ |

$N/2=5/2$ なので、各子の部分木が $5/2$ 以下であり、自身の部分木が $5/2$ より大きい頂点 $0$ が重心である。

頂点 $0$ を根にすると、各辺の葉側の頂点は次のようになる。
それぞれの頂点に、その辺番号を加えておく。

<!-- table-row-header: true -->
| 辺番号 | 両端の頂点 | 葉側の頂点 | 加える値 |
| ---: | :---: | ---: | ---: |
| $1$ | $(1,3)$ | $1$ | $1$ |
| $2$ | $(0,4)$ | $4$ | $2$ |
| $3$ | $(0,3)$ | $3$ | $3$ |
| $4$ | $(0,2)$ | $2$ | $4$ |

次に、重心から葉に向かって累積和を取る。
例えば頂点 $1$ は、頂点 $0 \to 3 \to 1$ の順にたどるため、累積後の値は $3+1=4$ となる。

各頂点について、累積後の値と、それを辺番号の総和 $1+2+3+4=10$ から引いた結果をまとめる。

<!-- table-row-header: true -->
| 頂点 | 加えた値 | 累積後の値 | $10$ から引いた値 |
| ---: | ---: | ---: | ---: |
| $0$ | $0$ | $0$ | $10$ |
| $1$ | $1$ | $4$ | $6$ |
| $2$ | $4$ | $4$ | $6$ |
| $3$ | $3$ | $3$ | $7$ |
| $4$ | $2$ | $2$ | $8$ |

したがって、答えは $10,6,6,7,8$ となる。

## 注意点

辺番号の総和 $N(N-1)/2$ は、`int` 型からはみ出る。
`long long` 型を用いること。
