## 考え方

入力は文字列が $1$ つ。
`string` 型の変数を用意し、`cin` で入力を受け取る。

さて、碁の先手を決めるためのルールである「ニギリ」のように、奇数か偶数かを正しく答えればよい。
これは、 `'o'` の個数さえわかれば、$2$ で割って余りを確認することで答えられる。

まずは前半戦、`'o'` の個数を数える作業。
まず、カウンターを $0$ で初期化して用意する。
その後、文字列を $1$ 文字ずつ確認し、`'o'` だったらカウンターを $1$ 増やせばよい。

しかし、これをforループで書こうとすると、文字数がわからないという問題が発生する。
そこで、`ssize()` を使って、$S$ の文字数を先に取得する。

```cpp
int n = ssize(S);  // n = S.size(); でもよい
for (int i=0; i<n; i++) {

}
```

この中で、if文を使って、「$i$ 文字目が `'o'` なら、カウンターを増やす」をすれば、`'o'` の個数が求まる。

続いて後半戦だが、こちらは簡単。
カウンターの値を `%2` してみて、それが $1$ だったら `"odd"` を、$0$ だったら `"even"` を出力すればよい。
if文の中で直接 `cout` してもいいし、出力用の変数を用意して書き換えてもよい。

## 入力例1での動作

入力を受け取る。

```text
s: "oo.o.o"
```

`result` を `"even"`、カウンターを $0$ で初期化する。
`ssize(s)` で文字数を取得すると、$6$ となる。

文字列を前から $1$ 文字ずつ調べ、`'o'` だったらカウンターを増やしていく。

- $i=0$：`'o'` なので、カウンターは $1$ となる。
- $i=1$：`'o'` なので、カウンターは $2$ となる。
- $i=2$：`'.'` なので、カウンターは $2$ のまま。
- $i=3$：`'o'` なので、カウンターは $3$ となる。
- $i=4$：`'.'` なので、カウンターは $3$ のまま。
- $i=5$：`'o'` なので、カウンターは $4$ となる。

最終的なカウンターは $4$ であり、$2$ で割った余りは $0$ なので、`result` は `"even"` のままである。
よって、`even` を出力する。
