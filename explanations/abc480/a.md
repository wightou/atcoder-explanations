## 考え方

入力は文字列が $2$ つ。
`string` 型の変数を $2$ つ用意し、`cin` で入力を受け取る。

`"Yes"` であるパターンより、`"No"` であるパターンの方が数えやすい。
というのは、`'A'` と `'D'` が対角線位置にいることを判定するだけですむためである。

よって、以下の $4$ つのいずれかに該当したら `"No"` である。

- 左上が `'A'` で、右下が `'D'` である。
- 右上が `'A'` で、左下が `'D'` である。
- 左下が `'A'` で、右上が `'D'` である。
- 右下が `'A'` で、左上が `'D'` である。

if文の条件に全て書いてもよいが、長くなって大変。
出力用変数を `"Yes"` で用意しておき、「該当したら `"No"` に変更」を $4$ つ書くのがわかりやすい。

文字コードの知識があれば、もっと簡単に書ける別解もある。

## 入力例1での動作

入力を受け取る。

```text
s1: "AB"
s2: "DC"
```

出力用変数を `"Yes"` で初期化する。

`'A'` と `'D'` が対角線上にあるか、$4$ つの条件を順に確認する。

<!-- table-row-header: true -->
| 条件 | 実際の文字 | 判定 |
| :--- | :--- | :--- |
| 左上が `'A'`、右下が `'D'` | 左上は `'A'`、右下は `'C'` | 該当しない |
| 右上が `'A'`、左下が `'D'` | 右上は `'B'`、左下は `'D'` | 該当しない |
| 左下が `'A'`、右上が `'D'` | 左下は `'D'`、右上は `'B'` | 該当しない |
| 右下が `'A'`、左上が `'D'` | 右下は `'C'`、左上は `'A'` | 該当しない |

どの条件にも該当しないため、出力用変数は `"Yes"` のままである。
したがって、`Yes` を出力する。

## 別解

`'A'` と `'D'` が左上と右下の組にある場合、それらの文字コードの和は $133$ である。

`'A'` と `'D'` が右上と左下の組にある場合、左上と右下は `'B'` と `'C'`。
それらの文字コードの和も $133$ である。

そして、左上と右下の文字コードの和が $133$ になるのは、この $2$ 通りの場合だけである。
よって、`"No"` であることを左上と右下の文字コードの和が $133$ かどうかで判定してもよい。
