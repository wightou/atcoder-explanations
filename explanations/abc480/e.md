## 考え方

初項、公差、項数の $3$ つのデータで全探索をかけたい。
しかし、入力例 $2$ からわかるように、$1$ つずつ数えていては間に合わない。
よって、どれか $1$ つは「ここからここまで」でまとめて処理する必要がある。

まず、項数の上限を考える。
初項 $1$ 公差 $1$ でも、項数 $20$ で積が既に $10^{18}$ を超える。
つまり、項数は最大でも $19$ まで考えればよい。

その前提で、各項数での初項と公差のありえる上限を考えると、以下のようになる。

<!-- table-row-header: true -->
| 項数 | 初項上限 | 公差上限 |
| ---: | ---: | ---: |
| $3$ | $999999$ | $707106780$ |
| $4$ | $31621$ | $550320$ |
| $5$ | $3979$ | $14286$ |
| $6$ | $997$ | $1527$ |
| $7$ | $369$ | $333$ |
| $8$ | $174$ | $109$ |
| $9$ | $96$ | $46$ |
| $10$ | $58$ | $23$ |
| $11$ | $38$ | $13$ |
| $12$ | $26$ | $8$ |
| $13$ | $18$ | $5$ |
| $14$ | $13$ | $4$ |
| $15$ | $9$ | $2$ |
| $16$ | $6$ | $2$ |
| $17$ | $4$ | $1$ |
| $18$ | $2$ | $1$ |
| $19$ | $1$ | $1$ |

全探索する方はこのまま、二分探索する方は $\log$ になり、それらの積にさらに項数を掛けたのが計算回数。
となると、全部まとめてどちらかで計算するなら、初項を全探索して公差を二分探索することになる。
初項側は小さい方から探索し、「公差が $1$ でもダメ」になった時点で打ち切りにすればよい。
公差の範囲は、初項 $1$ では $10^9$ あたりを上限としておき、次からは前の初項での値を上限とすればよい。
これは、初項が増えれば増えるほど公差上限が減ることから正しさが保証される。

計算量は $O(N^{1/3}\log N)$ である。
（長さ $3$ のときが計算量の大部分であり、長さ $4$ 以上は全部まとめてもそれ未満である）

## 入力例1での動作

入力を受け取る。

```text
n: 120
```

項数を $3$ から順に固定し、初項を $1$ から増やして最大公差を求める。
初項が増えるときには、直前の初項で求めた最大公差を次の公差上限とする。

項数が $3,4,5$ のとき、調査上限・最大公差・答えの累計は次のように変化する。
$\infty$ のところは、$10^9$ 程度の十分大きな値。

<!-- table-row-header: false -->
| 項数 | 初項 | 調査上限 | 最大公差 | 答えの累計 |
| ---: | ---: | ---: | ---: | ---: |
| $3$ | $1$ | $\infty$ | $7$ | $7$ |
| $3$ | $2$ | $7$ | $4$ | $11$ |
| $3$ | $3$ | $4$ | $2$ | $13$ |
| $3$ | $4$ | $2$ | $1$ | $14$ |
| $3$ | $5$ | $1$ | $0$ | $14$ |
| $4$ | $1$ | $\infty$ | $2$ | $16$ |
| $4$ | $2$ | $2$ | $1$ | $17$ |
| $4$ | $3$ | $1$ | $0$ | $17$ |
| $5$ | $1$ | $\infty$ | $1$ | $18$ |
| $5$ | $2$ | $1$ | $0$ | $18$ |

項数が $6$ から $19$ の場合は、いずれも初項 $1$ で最大公差が $0$ となり、その項数の処理を終了する。
答えの累計は変わらず、$18$ となる。

## 注意点

$N$ や答えは `int` 型からはみ出る。
`long long` 型を用いること。

数列の総積は計算途中で `long long` 型からはみ出る可能性がある。
乗算の前にオーバーフローを判定し、総積が $N$ 以下かどうかを正しく比較できるようにすること。
