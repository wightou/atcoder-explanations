## 考え方

まずは愚直にやることを考えてみる。
$N$ 人それぞれ、「自分が辞退したら誰が何票獲得するか」をカウントすればよい。
$1$ 人当たり $M$ 票を処理して $N$ 人のデータから最大値を探すので、$O(N(M+N))$ で求まる。
これではTLEなので、無駄な処理を省くことを考える。

まず、明らかに無駄なのは、毎回 $M$ 回の票を数えなおす点。
第一の人が辞退する場合以外は同じ処理を繰り返すだけなのだから、毎回やり直す価値は薄い。
よって、以下のようにすれば無駄が省ける。
- 最初に、各人について、以下の $2$ つを集計しておく
  - その人の第一希望得票数
  - その人を第一希望としている人の、第二希望一覧
- 各人が辞退した場合の調査時には、以下のようにする
  - 最初に、その人を第一希望としている人の第二希望一覧を全て見て、順に票数を $1$ 足す
  - 調査を実行する
  - 終わったら、その人を第一希望とする人の第二希望一覧を全て見て、順に票数を $1$ 引いて戻す

これで、$M$ 票の操作を $N$ 回やることを避けられ、$O(N^2+M)$ になる。
とはいえ、これでもまだ間に合わないので、さらに無駄を省く。

まだ $O(N^2)$ 回かかっているのは、票数最大値の調査である。
しかし、これも第二希望の票をもらっていない人を全て調査する意味はない。
当選する可能性があるのは、以下のどちらかに該当する人だけである。
- 第一希望の人が辞退したら無効票にするルールでの当選者
- 第二希望票をもらった人

前者は、番号の昇順と降順に累積最大値とその位置を求めて利用する。
自分より前と自分より後の最大値を比較すれば、「自分以外の最大値とその位置」を $O(N)$ で求められる。
（番号が昇順にほしいので、「票数の $-1$ 倍、番号」の `pair` の最小値を求めると実装しやすい）
後者は、票の数しか操作は行われないので、全体で $O(M)$ で済む。
よって、全体の計算量 $O(N+M)$ で解ける。

## 入力例1での動作

入力を受け取る。
入力された候補者番号を `0-indexed` に変換する。

```text
n: 5
m: 6
a: {0, 0, 1, 1, 2, 3}
b: {2, 2, 0, 0, 3, 1}
```

まず、第一希望の得票数と、各候補者が辞退した場合の第二希望投票先を集計する。
候補者番号を $1$ から $5$ として示すと、次のようになる。

<!-- table-row-header: true -->
| 候補者 | 第一希望得票数 | その候補者を第一希望とする票の第二希望一覧 |
| ---: | ---: | :--- |
| $1$ | $2$ | $\{3,3\}$ |
| $2$ | $2$ | $\{1,1\}$ |
| $3$ | $1$ | $\{4\}$ |
| $4$ | $1$ | $\{2\}$ |
| $5$ | $0$ | $\{\}$ |

次に、各候補者の左側と右側で第一希望得票数が最大となる候補者を、両側からの累積最大値で求める。
同票なら番号が小さい候補者を選ぶ。
左側と右側の候補者を比べ、得票数が多い方を選ぶ。
これが、第二希望票を無視した場合の当選者となる。
結果を、候補者番号を $1$ から $5$ として示すと次の通りになる。

<!-- table-row-header: true -->
| 辞退する候補者 | 左側の最良候補者 | 右側の最良候補者 | 第二希望票を無視した当選者 |
| ---: | :---: | :---: | ---: |
| $1$ | なし | $2$ | $2$ |
| $2$ | $1$ | $3$ | $1$ |
| $3$ | $1$ | $4$ | $1$ |
| $4$ | $1$ | $5$ | $1$ |
| $5$ | $1$ | なし | $1$ |

最後に、辞退する候補者を第一希望としている票だけを、第二希望へ移す。
候補者 $1$ が辞退する場合は、候補者 $3$ に $2$ 票が移り、得票数が $1$ 票から $3$ 票に増える。
元の暫定当選者である候補者 $2$ の $2$ 票を上回るので、当選者は候補者 $3$ に変わる。

ほかの候補者についても同じように、票を受け取った候補者だけを比較する。
辞退者ごとの結果は次の通りである。

<!-- table-row-header: true -->
| 辞退する候補者 | 第二希望票による変化 | 当選者 |
| ---: | :--- | ---: |
| $1$ | 候補者 $3$：$1\to3$ 票 | $3$ |
| $2$ | 候補者 $1$：$2\to4$ 票 | $1$ |
| $3$ | 候補者 $4$：$1\to2$ 票 | $1$ |
| $4$ | 候補者 $2$：$2\to3$ 票 | $2$ |
| $5$ | 変化なし | $1$ |

候補者 $3$ が辞退した場合は候補者 $1,2,4$ が同じ $2$ 票となるため、番号が最小の候補者 $1$ が当選する。
各辞退者の調査が終わったら、加算した得票数を元に戻す。
これで、次の調査は同じ第一希望得票数から始められる。
