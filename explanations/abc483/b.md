## 考え方

最後に表裏を符号で表せという指示がある。
しかし、途中でも表は $+$、裏は $-$ として積んでおけばよい。

その工夫を取り入れて、素直にシミュレーションをすればよい。
つまり、上から要求された枚数を $1$ 枚ずつ裏返しながら取り出し、取り出した順にそのまま戻せばよい。
`stack` か `vector` を使うとして、後ろが上になるようにすると実装しやすい。

## 入力例1での動作

入力を受け取る。

```text
n: 5
q: 2
a: {3, 5}
```

最初の山札は、下から順に $5,4,3,2,1$ であり、すべて表向きである。
表向きを正、裏向きを負として、山札を下から上の順に示す。

```text
山札: {5, 4, 3, 2, 1}
```

$1$ 回目は、上から $1,2,3$ の $3$ 枚を $1$ 枚ずつ取り出し、それぞれ裏返す。
このとき、取り出した順に並べると $-1,-2,-3$ となり、山札には $5,4$ が残る。

```text
山札: {5, 4}
取り出したカード（取り出した順）: {-1, -2, -3}
```

取り出したカードを $-1,-2,-3$ の順に、$1$ 枚ずつ山札の上へ戻す。

```text
山札: {5, 4, -1, -2, -3}
```

$2$ 回目は、上から $-3,-2,-1,4,5$ の $5$ 枚を $1$ 枚ずつ取り出し、それぞれ裏返す。
このとき、取り出した順に並べると $3,2,1,-4,-5$ となり、山札は空になる。

```text
山札: {}
取り出したカード（取り出した順）: {3, 2, 1, -4, -5}
```

取り出したカードを $3,2,1,-4,-5$ の順に、$1$ 枚ずつ山札の上へ戻す。

```text
山札: {3, 2, 1, -4, -5}
```

山札を上から順に読むと $-5,-4,1,2,3$ となる。
