## 考え方

途中から取り出して途中へ入れる操作と指示されている。
しかし、それらの間の区間以外は何も起こらないだけ。

ということで、$A$ と $B$ で先頭が同じ数である限り、それらを削除してしまってよい。
もし同じ数であって先頭を移動させる解がある場合、次の数を移動させる解もあるはずだからである。
入力を `vector` で受け取ると計算量が大変なことになるので、 `deque` で受け取って行うこと。
また、末尾も同様に、同じ数である限りそれらを削除してしまってよい。

すると、問題は単純になる。
$A$ の端の数を逆の端へ移動して、$B$ に一致させることができるか？
`deque` でやっているのであれば、実際に動かして `==` で判定すればよい。

計算量は $O(N)$ である。

## 入力例1での動作

入力を受け取る。

```text
n: 6
a: {1, 4, 1, 4, 2, 1}
b: {1, 4, 1, 1, 4, 2}
```

先頭から $1,4,1$ が順に一致しているので、両方から削除する。
残った数列は次の通りである。

```text
a: {4, 2, 1}
b: {1, 4, 2}
```

末尾は $1$ と $2$ で異なるため、末尾からは削除しない。

まず $A$ の先頭の $4$ を末尾へ移すと $A=(2,1,4)$ となり、$B=(1,4,2)$ には一致しない。

元の $A=(4,2,1)$ に戻し、今度は末尾の $1$ を先頭へ移すと $A=(1,4,2)$ となり、$B$ に一致する。
したがって、答えは `Yes` である。
