このZIPはメタ・スクリプト類を中心とした差分配布です。
問題解説本文・生成済みHTMLを誤って上書きしないため、次のディレクトリは原則として含めていません。

- explanations/
- docs/
- __pycache__/

ただし v98 のタグ定義変更を反映するため、次の知識記事だけは意図的に含めています。

- knowledge/fps-convolution.md
- knowledge/counting-technique.md

反映方法:
1. ZIPをリポジトリ直下に展開します。
2. 必要なら次を実行して生成済みHTMLを更新します。

```bash
python scripts/build_site.py
```

知識記事のスタブを作る場合は、次を実行します。

```bash
python scripts/create_knowledge_stubs.py
```

Windows由来の `*:Zone.Identifier` ファイルを消す場合は、リポジトリ直下で次を実行します。

```bash
./scripts/delete_zone_identifier.sh
```
