# 競技プログラミング 知識集積所

AtCoderで解いた問題について、自分用に作成した解説をまとめています。

公開サイトはこちらです。

https://wightou.github.io/atcoder-explanations/

## 内容

- 問題別解説
- 使用したアルゴリズム・データ構造のタグ整理
- 知識記事
- GitHub Pages用の静的サイト生成スクリプト

## ディレクトリ構成

```txt
.
├── explanations/   # 問題別解説のMarkdown
├── knowledge/      # 知識記事のMarkdown
├── scripts/        # サイト生成スクリプト
├── docs/           # GitHub Pagesで公開する生成済みHTML
├── site_config.toml
└── README.md
```

## 利用について

解説および解答例としてリンクされている提出コード等については、自身の学習を目的として利用する場合に限り、配信での利用やAIへの読み込みを行ってもかまいません。
